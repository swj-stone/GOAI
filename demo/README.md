# CampusMatch Demo

CampusMatch 是一个面向普通学生的证据化求职辅助 Demo。学生只使用浏览器，不需要接触 Python、模型配置、API Key 或提示词。

## 开发环境

- Python：项目根目录 `venv/Scripts/python.exe`
- 依赖清单：项目根目录 `requirements.txt`
- Web：FastAPI + 原生 HTML/CSS/JavaScript
- 默认端口：`3100`

项目按 `show/18-Demo实现计划-HiClaw实机版.md` 逐项实现。未完成的功能不会在材料中标记为已实现。
