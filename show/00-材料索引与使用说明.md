## 当前完成度口径

- 已完成：产品定位、场景闭环、Agent 分工、Skill 与工具契约、数据与证据模型、安全边界、评测方案、Demo 复现设计、初赛 PPT。
- 尚未声称完成：可执行 AgentTeams 代码、真实高校试点、真实岗位匹配效果数据。
- 初赛展示可采用：方案 PPT＋离线样例输入输出＋可复现 Demo 设计。
- 入围复赛后实施：AgentTeams 编排、Worker Skill、前端可视化、Trace 与自动评测。

## 推荐提交顺序

1. 使用 `01-作品简介-500字内.md` 填写作品简介。
2. 提交 `CampusMatch-初赛方案.pptx`，同时导出 PDF 作为兼容备份。
3. 如允许补充链接，提供代码仓库或材料包，并在 README 中链接本文件。
4. 初赛截止前不把“目标指标”写成“实测结果”。

## 统一表述

一句话介绍：

> CampusMatch 让高校就业服务从黑盒推荐变为可追溯、可解释、可审批的多 Agent 求职协同闭环。

差异化表达：

> 系统不替学生包装不存在的经历，也不替企业自动淘汰候选人；它把简历证据、岗位要求、匹配理由、改进建议和审计记录连接成一条可回放的证据链。
