## 当前完成度口径

已完成并可现场运行：

- 无代码浏览器界面，普通用户无需 Python、API Key 或提示词；
- Markdown、TXT、DOCX、可提取文本 PDF 转 Markdown；
- Profile、Job、Match、Coach、Audit 的确定性业务链；
- 原文证据、行号、逐项匹配、环形图和五维图；
- 歧视条件隔离、审计阻断、人工批准和 Markdown 导出；
- HiClaw Manager/Controller、六个 Worker、六个 Skill 与 `mcp-campusmatch`；
- Manager 和所有 Worker 的 MCP 健康检查；
- 六阶段 MCP 烟雾测试以及真实 Team Room 委派链路；
- 自动化测试、依赖检查、浏览器桌面/移动端与控制台检查。

仍未声称完成：真实高校试点、真实招聘数据效果、自动录用决策、生产级身份系统、持久化数据库和扫描 PDF OCR。

## 推荐提交与演示顺序

1. 报名系统填写 `01-作品简介-500字内.md`。
2. 提交 `CampusMatch-初赛方案.pptx`，另导出 PDF 兼容备份。
3. 如允许附链接，提交仓库，并将入口指向 `demo/README.md`。
4. 现场先展示浏览器链路，再用 HiClaw Team Room 证明多 Agent 真实执行。
5. 只把 `19-Demo实机验收记录.md` 中已通过的内容表述为“已实现”；目标指标仍明确标注为目标。

## 统一表述

一句话介绍：

> CampusMatch 让高校就业服务从黑盒推荐变为可追溯、可解释、可审批的多 Agent 求职协同闭环。

差异化表达：

> 系统不替学生包装不存在的经历，也不替企业自动淘汰候选人；它把简历证据、岗位要求、匹配理由、改进建议和审计记录连接成一条可回放的证据链。
