# 作品简介（500 字以内）

## 项目名称

CampusMatch——高校可信求职协同基座

## 正文

CampusMatch 面向高校就业服务中心与在校学生，解决简历信息分散、岗位要求难比较、个性化辅导人力不足，以及现有 AI 建议缺少证据、容易虚构经历的问题。系统以 AgentTeams 为协同基点，由 Career Navigator、Profile、Job、Match、Coach、Audit 六类 Agent 完成材料解析、岗位规范化、证据匹配、求职辅导、模拟面试和安全审计。学生上传简历、课程与项目材料后，系统保留原文件并生成带行号的 Markdown 与结构化证据；每个能力、匹配结论和修改建议均可回溯原文。高风险输出由 Audit Agent 检查隐私、歧视性岗位条件、证据缺失、违法有害内容和经历虚构，通过人工确认后方可导出。核心能力沉淀为可复用 Skill，并规划通过 MCP/等价契约接入文件解析、岗位库、知识库和可观测系统。项目可复制至高校就业中心、职业培训机构和校招平台。当前已完成完整方案、Agent Identity、Skill 契约、样例数据与 Demo 复现设计；入围后将完成 AgentTeams 可运行版本、可视化匹配报告与自动评测。
