# CampusMatch 交付验收记录

验收日期：2026-08-14
验收范围：`show` 初赛材料、`demo` 可执行程序、HiClaw 集成与方案 PPT。

## 已通过的材料检查

- 作品简介正文不超过 500 字，保留“辅助而非自动招聘决策”的边界。
- PPT 为 16:9，覆盖真实场景、Agent 分工、Skill、证据模型、匹配解释、安全审计、Demo 和实施计划。
- 合成案例数字明确标注为演示结果，不表述为录用概率。
- 真实指标和目标指标分开；未声称存在真实高校试点或招聘效果数据。
- 风险属性使用 `POLICY_EXCLUDED`，不进入匹配分数或能力缺口。
- 外部来源保留在演讲者备注的 `[Sources]` 区块。

## 已通过的可执行 Demo 检查

- 项目根目录 `venv` 可运行，依赖由 `requirements.txt` 固定。
- 浏览器界面可载入合成案例、运行分析、展示 77 匹配度和 85 证据覆盖度。
- Profile 输出的能力均关联原文证据、来源与行号。
- Job 区分硬性要求、加分项、职责和风险条件。
- Match 展示“符合／部分符合／缺少证据”与五维可视化，不只给黑盒分数。
- Coach 的建议仅使用真实材料，不虚构经历或成果数字。
- 未人工批准时 Audit 返回 `BLOCK` 且导出禁用；批准后返回 `PASS` 并可导出 Markdown。
- Audit 会阻断原始证据中的手机号、身份证号或邮箱；风险条件若被误计分也会阻断导出。
- `.md`、`.txt`、`.docx` 和可提取文本 `.pdf` 可转 Markdown；扫描 PDF 会明确报错。
- 桌面端和 390px 移动端均可使用，浏览器控制台无错误或警告。

## 提交前仍需参赛者完成

- 补充团队名称、成员、学校、联系方式和报名系统要求字段。
- 在另一台安装 PowerPoint/WPS 的电脑上打开 PPTX，确认字体替换未影响版式。
- 按报名系统要求导出 PDF 兼容备份。
- 若创建公开仓库，补充许可证，并确认 `demo/.env.local`、真实简历和任何凭据未被提交。
- 现场演示前运行 `demo/scripts/preflight.ps1` 和 README 中的测试命令。

## 完成度边界

当前版本是可现场复现的本地 MVP 和 Agent Infra 证明，不是生产招聘系统。任务状态仍为进程内存存储；没有生产级数据库、OCR、账号权限、数据留存与删除管理，也没有真实就业结果评测。以上内容不得在答辩中描述为现成功能。
